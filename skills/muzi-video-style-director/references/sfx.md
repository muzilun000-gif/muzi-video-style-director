# 代码合成音效（无素材下载）

用户说“加点音效”而没有授权音效库时，用代码合成。库与混音器：[assets/pixel-mv/sfx_synth.py](../assets/pixel-mv/sfx_synth.py)（`--preview` 先把所有音色排一遍试听）。

## 原则

1. **音效跟画面事件走，不跟节拍走**：每个声音对应一个看得见的动作（落地、按键、翻页、快门、脚步）。没有画面动作的地方不加。
2. **压在歌声下面**：整体约比原曲低 14 dB（线性 0.05–0.15）；歌声段落更轻，前奏/间奏/无声段落可以大 1.5–2 倍。
3. **铺底 + 点缀**：雨声、低频嗡嗡这类长音做铺底，前后各淡 0.5–0.8s；点缀音短、干净。
4. **给全片留一个最亮的声音**：比如故事里第一次真正响起的琴键“叮”。其它铃声都要比它暗、比它轻。
5. **叙事里“说不出口”的地方用无音高声音**：喊话只给低频冲击 + 风声，不合成人声。

## 音色配方（都从白噪声或正弦波开始）

| 声音 | 做法 | 用在 |
|---|---|---|
| 叮（琴键/提示） | 基频 + 2.76/5.4/8.9 倍非整数泛音，指数衰减 | 关键时刻、标题落字 |
| 闷响（哑键/落地） | 90→50Hz 下滑正弦 + 开头 200 采样带通噪声 | 按不响的键、冲击 |
| 雨 | 300–6000Hz 噪声 + 80–400Hz 低频 + 随机高频水滴 click | 铺底 |
| 纸张/树叶 | 大量 10–50ms 带通噪声颗粒 | 翻页、照片、衣物 |
| 铅笔 | 3–9kHz 噪声 × 抖动节律包络（rate≈11）；rate 降低 = 橡皮 | 写字、涂掉 |
| 风声/转场 | 低频噪声渐变到高频噪声，sin² 包络 | 幕布、换季、冲刺 |
| 气泡 | 900→280Hz 快速下滑正弦 | 文字弹出、对话泡 |
| 脚步 | 110Hz 短正弦 + 带通噪声，按步频排 | 走、跑、上楼 |
| 吱呀 | 方波 260→400Hz + 30Hz 颤动，带通 | 秋千、门 |
| 倒带 | 500→2000Hz 上扫正弦 + 噪声 | 现在↔回忆 |
| 水滴/冰块 | 高频短铃 | 杯子、眼泪、水坑 |
| 嗡嗡 | 55Hz + 110.5Hz（微失谐产生拍频） | 琴肚、压抑 |
| 快门 | click + 短噪声 + 80ms 后第二个 click | 拍照、定格 |

## 混音与导出

- 原曲用 ffmpeg 解码成 float，和音效相加，**软限幅**（0.8 以上用 tanh 平滑压到 0.98 内），结尾与画面一起淡出。
- 同时导出 `*_sfx_only.wav`（音效放大 3 倍）给用户单独试听。
- 封装 AAC 时预留 −1.5 dB：WAV 峰值 0.98 编码后会贴到 0 dB。导出后跑 `scripts/audio_peak.sh` 确认峰值 ≤ −0.5 dB。
- 长度相加报错多半是采样数差 1：统一用 `round(dur * SR)`；组合音效分两次 `add`，不要直接相加两个不同长度的数组。

## 背景音乐（用户提供）

- 先量：`ffmpeg -i music.mp3 -af ebur128 -f null -` 看 Integrated；`volumedetect` 看分段均值。流行曲母带常在 −10 LUFS 左右，作知识片铺底要压低约 17 dB（整片落在 −25 LUFS 上下，音效峰值仍清楚）。用户说“不要太大声”就从 −17 dB 起，再按反馈 ±3 dB 调。
- 从哪进：默认第 0 秒进，开头 0.4s 快速淡入防爆音。用户要求前，不要自作主张推迟到片名后。
- 长度不够：在曲尾前 3s 把曲子开头交叉淡入补满，结尾随画面淡出 1.5s；接缝时间点在报告里写出来让用户重点听。也可以给“曲尾自然收、最后几秒只留音效”的备选。
- 有音乐就去掉自己合成的和弦长音（会和原曲和声打架），音效保留并叠在音乐上。
- 没有 numpy 时在临时目录建 venv：`python3 -m venv venv && venv/bin/pip install numpy`，用 venv 的 python 跑 `sfx_synth.py`。
- 版权：提醒用户确认曲子授权，平台可能识别。
