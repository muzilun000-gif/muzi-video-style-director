# 社交作品视觉参考

筛选日期：2026-10-22。六张预览均已实际查看。以下是第三方作品的外链参考，**不是本 skill 生成的图片，不代表已复现效果**。保留原作者与作品入口，不将图片打包进本仓库或授予 MIT 许可。

前三个方向优先用于吸睛封面：全息光球、液态金属字体、霓虹微缩城。下面的制作建议是本项目独立整理的方向，实际动作尚未渲染验收。

## 01 全息光球：AI 主题的首选方向

[![全息光球，AmazingUI 的作品](https://cdn.dribbble.com/userupload/44953737/file/still-93334749065a32b98ef1b91d5f9695d3.png)](https://dribbble.com/shots/26539318-Sphere-AI-Assistant)

- 作者与原帖：[AmazingUI — Sphere / AI Assistant](https://dribbble.com/shots/26539318-Sphere-AI-Assistant)。作者页与预览已读取。
- 吸睛点：纯黑背景、一个大主体、紫蓝与橙色边光；缩小后轮廓仍然清楚。
- 对应已有风格：`spatial` / `rhythm`。用于 AI 思考、数据汇聚、工具启动等抽象主题。
- 原创实现方向：设计自己的球体与曲面条带；低成本先用渐变圆形和遮罩验证构图，需要真实空间关系时再用 Three.js。转动、呼吸亮度和镜头推进中只选一个主动作。
- 封面改编：主体占画面约 60%，标题置于上部留白，用自己的中文标题；不照抄原图。

## 02 液态金属字体：把标题变成主视觉

[![液态金属字体，Pixelbuddha 的作品](https://cdn.dribbble.com/userupload/14153829/file/original-467faaa1769f211ce4c1b48d9f39f9d4.jpg?resize=1600x1200)](https://dribbble.com/shots/24025614-Glossy-Chrome-Text-Effect)

- 作者与原帖：[Pixelbuddha — Glossy Chrome Text Effect](https://dribbble.com/shots/24025614-Glossy-Chrome-Text-Effect)。作者页与预览已读取。
- 吸睛点：黑底、银色轮廓、细密彩色反射，大字本身就是画面。
- 对应已有风格：`kinetic` / `collage`。适合“18 种视频风格”之类短标题。
- 原创实现方向：先用 2D 字形遮罩、分段高光渐变和轻微位移做概念关键帧；真正的圆润挤出与反射需要 3D 几何、灯光和渲染。先检查中文笔画是否仍可辨读。
- 素材边界：原图的“Free”标签不等于所有版本都可免费商用或再分发。若使用其实际模板，需要另查对应下载页许可。

## 03 霓虹微缩城：把智能体工作流变成空间

[![霓虹微缩城，Fabricio Rosa Marques 的作品](https://cdn.dribbble.com/userupload/41923470/file/original-7cc5c99c3b73086787046f5a7fa25e0d.png)](https://dribbble.com/shots/3760609-Isometric-Neon-City)

- 作者与原帖：[Fabricio Rosa Marques — Isometric Neon City](https://dribbble.com/shots/3760609-Isometric-Neon-City)。作者说明使用 MagicaVoxel；页面与预览已读取。
- 吸睛点：蓝紫双强调色、块状建筑、亮暗分层，空间关系比平面方框更有趣。
- 对应已有风格：`isometric` / `pixel` / `spatial`。
- 原创实现方向：用自己的城市布局，分别把选题、脚本、画面、导出设计成四栋功能建筑；任务用一条沿街移动的光点表达。低成本用等距 SVG，真实环绕镜头再选 3D。

- 作者与原帖：[Artemii Lebedev — Floral Grasp, 3D Motion Poster](https://dribbble.com/shots/21064773-Floral-Grasp-3D-Motion-Poster)。作者页与预览已读取。
- 吸睛点：金属手与透明容器的材质反差，大面积黑色留白。
- 对应已有风格：`spatial` / `editorial`。
- 原创实现方向：选一个与主题有关的物体，如“装着文字的玻璃盒”；改变主体、构图和排版。玻璃折射与复杂手部不是低成本代码图形的默认能力，先做单镜头与渲染耗时检查。

## 06 像素魔法场景

[![像素魔法师，majidmanzarpour 的案例预览](https://media.skillry.dev/opus-5-5/majidmanzarpour-927543/original.f5bc33c897.webp)](https://x.com/majidmanzarpour/status/2102476258948927543)

- 作者与原帖：[@majidmanzarpour](https://x.com/majidmanzarpour/status/2102476258948927543)。由同一公开案例索引发现，已查看 original 缩略图；未完整观看原视频或独立核实制作模型。
- 吸睛点：明确角色、月夜背景、法杖高亮，容易转化成“输入指令 → 释放能力”的小故事。
- 对应已有风格：`pixel` / `comic`。
- 原创实现方向：设计自己的角色、道具与关卡；用低分辨率 Canvas、最近邻放大和有限调色板表现像素，不把普通矢量画面仅加颗粒就称为像素风。

## 怎样用这些参考

1. 用户说“酷一点”时，优先展示与其主题相关的两张，说明主体、材质、颜色各借鉴什么；已选风格就直接推进。
2. 在 `LOOK.md` 记录参考原帖、学习的视觉原则、原创主体、排版与颜色的改动。
3. 先做 9:16 首帧和最复杂一帧，缩到手机尺寸检查。中文标题通常控制在两行内，别沿用参考里的英文密集小字。
4. 参考画面、原创关键帧、运行中的动画、已验收 MP4 分别标记。只有实际完成后才能作为 skill 效果展示。
