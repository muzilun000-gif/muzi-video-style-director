# 案例：《一句玩笑的信号损耗》知识动画片

一个具体项目的复盘，只在做无配音、横屏、有研究依据的知识动画片时阅读。方法总结见 [知识动画片](../knowledge-video.md)。

## 项目概况
- 账号：认知 / 沟通 / 学习 / 思维误区方向，横屏、无配音、画面文字讲述，作品 1–4 分钟。
- 选题来源：用户爆款《一句行吧，为何吵起来？》的续作方向；依据 Kruger, Epley, Parker & Ng (2005) *JPSP* 89(6) 的 5 个实验 + Newton (1990) 敲桌实验。
- 主题：「语气，是发不出去的」。母题：语气波形穿过发送键被压平；50% 硬币；阿杰和小林的群聊。
- 成片：2:48，1920×1080，30fps，16 个镜头，12 个知识单元；Canvas `renderAt(t)` + 本机 Chrome 无头渲染（[render.mjs](../../assets/canvas-render/render.mjs)）；代码合成 291 个音效点 + 用户提供的背景音乐压低 17 dB。

## 出过的错（已修，下次提前避免）
- 字符解码函数的阈值让最后几个字永远到不了，标题停在“自我中心偏H”。阈值按 `i / n * 0.75` 分布，保证 k=1 时全部落定。
- 琥珀差距块盖住“84%”“62.8%”等数字：差距柱的数字放柱内或柱下。
- 第一版在“念出来”一侧也画了高估差距，但原文该条件下预计与实际无显著差别 → 删除。数据图先对原文结论再画。
- 背景音乐第一次从片名处（7.9s）进入，用户要求从开头进。
