# 像素风音乐MV：代码管线与画面规则

用于“纯代码画像素MV”“像素角色+歌词”“整首歌的像素动画”。和 [MV 与动态歌词](music-video.md) 一起用：那份管歌词层与验收，这份管像素画面怎么做得不平庸。实例见 [案例：《哑键》](cases/yajian-pixel.md)。

## 1. 管线（先跑通再加戏）

| 项 | 推荐值 | 原因 |
|---|---|---|
| 内部网格 | 480×270（16:9）/ 270×480（9:16） | ×4 正好 1080p；像素块够大，手机上能看出“像素感” |
| 放大 | 最近邻 `repeat(4,0).repeat(4,1)` | 任何插值都会糊边 |
| 帧率 | 60fps（动效多）/ 30fps（省时） | 逐字动画和粒子在 60fps 更顺 |
| 输出 | raw RGB 管道 → ffmpeg libx264 CRF 15–16 | 像素硬边在 CRF>20 会出现色块 |
| 并行 | 按帧号切 N 块，每块一个 mp4，`concat` 后 `-c:v copy`，最后封装音频 | 4 分钟 60fps 单进程要数小时 |
| 字体 | 系统中文黑体，整数字号 12/16/24/36，`fontmode='1'` | 关掉抗锯齿才是像素字 |
| 半透明 | Bayer 4×4 有序抖动，不用 alpha 混合 | 混合出的中间色会破坏像素调色板 |

起步代码：[assets/pixel-mv/pixel_core.py](../assets/pixel-mv/pixel_core.py)（网格、花字、氛围层、转场、并行渲染，含 4 秒演示）。
先 `--still 2.0` 出单帧 PNG 看构图，再渲短片，最后整首。整首渲染前做一张**镜头表**（每个镜头取中间帧拼成网格，见 `scripts/contact_sheet.sh`）一眼查重复和空镜。

文件组织建议：`fx`（花字）/`portrait`（大头像）/`sprites`（小人）/`decor`（道具库）/`rooms`（场景变体）/`atmos`（氛围层）/`scenesN`（镜头函数）/`sfx`（音效）/`mvfull`（时间轴 SHOTS 表 + 渲染入口）。镜头函数签名统一为 `shot(t, t0, **mode) -> frame`。

## 2. 角色：远景小人和近景大头必须是同一个人

用户最容易一眼看出“像两个人”。先定 **3–4 个识别锚点**，两种尺度都画出来：

- 发型轮廓（齐刘海 / 刺头）——最远也能认出
- 一个固定颜色的小配饰（黄色方形发夹、耳机）——位置固定在同一侧
- 服装主色和领口（藏青水手领 + 红领结、黑色书包肩带）
- 体型与脸型比例（圆脸、大眼）

近景大头（约 200×210 网格像素）要“真实不糊”：
- 眼睛：上睫毛线 + 双眼皮 + 4 层虹膜（深→浅）+ 2 个高光点；眼睛比写实大，是表情主力。
- 头发：先整体剪影，再加分缕、发丝高光（光环形）、随时间轻微摆动；刘海不要做成扇形放射。
- 轮廓：外描边 + 一侧轮廓光（rim light）把人从背景里抠出来。
- 表情参数化：`look`（视线）、`mouth`、`blush`、`eyes`（开/半闭/闭）、`brow_up`，用同一张脸演不同情绪。
- 小人 sprite 用字符画调色板（`'R'`=红领结），改设计时写一个函数统一替换正/侧/背三个朝向，再生成表情变体。

## 3. 构图：人物在一侧，歌词在另一侧

近景特写“人物在右、歌词在左”很受欢迎：人物占画面右 55%，左侧留给大小字错落的歌词。镜头函数里登记人物保留区（脸、手），光斑、雨滴、前景物都绕开它。

## 4. 场景装饰规则（最常被说“平庸”的地方）

**每个场景 = 主体 + 至少 3 件道具 + 1 层前景 + 1 种动态元素。** 只有一栋楼、一扇门、一个房间的画面一律不合格。

| 场景 | 道具示例 | 前景 | 动态 |
|---|---|---|---|
| 教室/音乐室 | 黑板文字、吊扇、彩旗、花瓶、热水瓶、日历、软木板、相框 | 虚化窗框、盆栽、桌角 | 吊扇转、窗帘飘、粉尘 |
| 走廊 | 储物柜、公告栏、值日表、灭火器、门牌 | 柱子 | 路过同学剪影 |
| 屋檐/雨天 | 伞架、排水管、爬山虎、自动售货机、自行车 | 滴水檐口 | 雨、溅水、倒影 |
| 校门 | 横幅、门卫亭、行道树、路灯、花坛、斑马线 | 树枝叶片 | 飞鸟、花瓣 |
| 操场/秋千 | 树、长椅、远处球门 | 草叶 | 秋千摆、光斑 |

**同一地点出现 3 次以上必须变体**：换黑板/海报文字（合唱比赛 → 期中考试 → 元旦晚会 → 毕业快乐）、换季节道具（向日葵 → 枫叶 → 松枝；风扇 → 暖气、围巾、剪纸雪花）、换光和调色、换窗外天气；“现在”版本盖布、堆纸箱、蛛网、冷调。实在撑不住就换地点。

道具库写成函数 `prop(g, x, y, t=0, seed=...)`，种子必须是非负整数（`abs(int(x))`），否则 `default_rng` 报错。前景叶子用实心、有方向的叶片；抖动点阵的叶团看起来像脏点。

## 5. B-roll：让情绪有多种表达

不要整首都是“人站着 + 歌词”。每个段落换一种表达方式，例如：
- 物件特写：两杯饮料的冰块、铅笔写了又擦的心、塞进琴键缝的纸条
- 手部特写：教琴的两只手、指尖快碰到又收回
- 分屏/对称：两人在墙两侧、同一时刻的两个窗口
- 时间流逝：倒计时黑板、钟表、四季同一窗口
- 实物文字：同学录写了又划掉、信纸上的泪痕
- 拍立得/照片落在桌上（见下节）
- 风格突变：双重曝光、录像带倒带、音符化的树叶
- 跑动：多层视差 + 残影 + 速度线

## 6. “太素”的画面怎么救：氛围层清单

照片墙、人物特写最容易显得空。按“背景 → 主体 → 光 → 前景 → 镜头”叠层：

1. **背景有生活痕迹**：虚化书架、绿植、钟、台灯、串灯；户外是远处路人剪影、飞鸟。
2. **照片不悬空**：落在书桌上（木纹、旧乐谱、冒热气的茶、主角的标志配饰、压花、纸条、铅笔），一张张落下、晃动、贴和纸胶带。
3. **光**：窗光斜束 + 树影/雨痕、`dapple` 光斑（脸上 ≤0.14，否则像迷彩）、镜头光晕 `flare`、灰尘 `motes`。
4. **前景**：飘动的窗帘边、窗框、树枝、前景虚化光斑 `front_bokeh`（避开脸）、镜头雨滴 `lens_drops`。
5. **镜头质感**：暗角 `vignette`、胶片颗粒 `grain`、漏光、整体调色 `grade`。

## 7. 动效清单（“更多创意”时从这里挑）

- 花字逐字进场：drop/pop/rise/flip/slide/press/spin/stretch，相邻字不同、带轻微高低错落和歪斜，进场后呼吸。
- 歌词大小字：重点词放大 1.5–2 倍、换色、单独动画；小字安静地 rise。可加跳动的小音符、下划线扫过。
- 转场：点阵溶解（默认 0.25s）、琴键擦除、幕布合开、白闪、录像带倒带（现在↔回忆）。每种有固定语义，不随机用。
- 气泡/想法：说不出口的话变成“…”或被涂掉。
- 冷暖切换：现在 = 冷灰蓝降饱和，回忆 = 暖黄褪色，结尾的关键一刻暖色淹没画面。

## 8. 常见坑

- `np.roll` 做描边/膨胀会把底边绕到顶上：先 pad 或清边。
- 切片形状差 1 像素（120 vs 128）：裁剪统一用 `[y0:y1:step]` 并断言形状。
- 绘制顺序：坐在课桌间的人要插在两排课桌之间画，不能最后整体盖上。
- 道具挡主体：花瓶挡黑板、伞杆穿脸——每个镜头出图后先看主体是否被挡。
- 测试函数放在 `__main__` 之后重定义不会生效：样张脚本单独成文件。
- 渲到一半要改：直接停掉，改完重渲；不要拿半成品拼。
