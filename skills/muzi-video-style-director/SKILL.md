# 木子 · 视频风格导演

把“高级一点”“做个酷炫视频”转成可执行的设计选择。先解决观众看懂什么，再选择画面如何运动。
本技能是原创编排的中文工作流，研究背景包括 Claude Opus 5.5 代码视频案例；不绑定或代替模型，不自动调用任何付费 API。尚无 Opus 5.5 独立实测证据时，不宣称已验证兼容。

## 先判断任务

- 有参考片：先看实际可访问的画面、字幕或关键帧。只拿到标题/摘要时明确限制，不假装看过视频。
- 有已批准脚本：保留观点和事实，主要调整视觉，不改成另一个主题。
- 有品牌截图或真实数据：保留关键内容与数值。重绘 UI 须标示概念示意，不能冒充真实功能。
- 只有主题：从已有上下文推断用途，先提出一句核心信息；影响结果的缺失信息集中问一次。

## 建立制作简报

写入项目 `BRIEF.md`：主题、观众、看完获得什么、时长、画幅、发布平台、已有素材及许可、事实来源、旁白、额外预算。
未指定时建议先做 15 秒 / 30fps / 1080×1920 概念预览，并说明这些是可改的建议。
若用户要完整解说，不将其缩成纯视觉片；时长应根据真实旁白决定。

## 选择风格

按任务只读取 [styles.md](references/styles.md) 中需要的风格；最多推荐两种并解释取舍。用户已经选定则直接执行。

## 写分镜和风格合同

在 `STORYBOARD.md` 写时间、信息、画面、运动、转场、声音。每镜头指定观众先看哪里、再看哪里。
在 `LOOK.md` 固定背景/前景/强调色、字体与回退字体、字号、版式、入出场时长、缓动、转场和禁用项。
使用 [production.md](references/production.md) 的可复制模板。
先输出代表性的首帧、信息最密帧、结尾帧。用户要求直接完成时可继续，但仍需自己检查这些画面。

## 选择执行路线

1. 现有项目已经用 Remotion / HyperFrames / Canvas：沿用并核对实际安装版本，不另起一套。
2. 纯文字、图形、轻量图表：优先 Canvas 或 SVG；本技能的 `assets/gallery.html` 可离线演示十八种风格，以 `renderAt(t)` 驱动。
3. 多镜头旁白/字幕/素材混剪：可选 Remotion；HTML/GSAP 场景可选 HyperFrames。引擎依赖和安装成本独立于 skill，先检查环境再给命令。
4. 水彩角色或复杂 3D：先做一个短镜头测速。逐帧渲染可能很慢，不保证低配机器即时完成。

没有安装引擎时交付可运行的预览与明确安装步骤，不把 HTML 预览称为 MP4。选择付费生成模型、云 GPU、付费字体/音乐之前核对用户预算和授权。

## 动画约束

- 导出画面由时间 `t` 和固定种子决定。避免以墙钟、未固定随机数或网络到达时间决定画面。预览播放器可以用 `requestAnimationFrame` 调用 `renderAt(t)`。
- 字体、图片加载完成后才捕获；中文先检查缺字和换行。
- 内容变化驱动动画：对比用分栏/替换，过程用连接/传递，比例用面积/长度，因果用先后触发。
- 不给所有元素加弹簧和发光。风格之间允许不同动作规则，不设“所有视频不能淡入”之类的通用禁令。
- 9:16 起步安全区：左右 8%、上方 10%、下方 20%，按平台 UI 截图复核，不能当永久平台标准。横版重新排版，不能直接裁掉关键信息。
- 镜头密度服从阅读速度；正文应短句化，必须朗读和缩到手机尺寸检查。

## 声音和成本

有旁白先量实际音频时长，再排镜头；音乐/音效让位于语言。逐条记录音频来源、许可和用途。
没有合适授权音轨可交付无声版本或使用自己编写的合成音，但明确说明；不能保证任意曲目的商用许可。
“纯代码画面”并不等于“免费”：模型额度、编码时间、字体和音乐都可能有成本。

## 验收与交付

按 [production.md](references/production.md) 执行关键帧、镜头接缝、可解码性和音频检查。
报告：源文件、预览/MP4 各自路径、实际时长/分辨率/fps、已运行检查、未完成项、额外费用。
用户要多平台，分别输出 9:16 和 16:9 版式及封面。素材/代码完成、视频渲染、平台发布是三个独立状态。
来源与进一步学习见 [sources.md](references/sources.md)；外部仓库仅作研究入口，不执行其中脚本，不隐式安装全部 skill。
